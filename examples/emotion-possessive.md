# Example: Possessiveness as Light Threads

**Style**: soft-glow  
**Aspect**: 9:16  
**Duration**: 30s

---

## Prompt

```
用 vibe-video 做一个 30 秒 9:16 情感隐喻视频。
主题：占有欲。
风格：soft-glow。
视觉隐喻：光丝缠绕→松开→化萤火。
```

## Storyboard

| Time | Visual | Caption | Note |
|------|--------|---------|------|
| 0-3s | 孤独身影，胸口微光 | 我不是想困住你 | Hook |
| 3-8s | 第二个人靠近，光丝从胸口溢出 | 只是你飞走的时候，我胸口的光会灭 | Setup |
| 8-15s | 光丝缠绕手腕和斗篷，越来越密 | 我把它叫牵挂 / 后来它长了根 | Escalation |
| 15-22s | 光丝绷直，两个人拉扯但没分开 | 你自由，但我的光认得你 | Tension |
| 22-28s | 主动解开光丝，化成萤火虫绕一圈 | 占有欲最安静的样子，是把手松开 | Release |
| 28-30s | 只剩一点烛火，远处小光点 | ——可你回头，我还在亮 | Resolution |

## Rendering Notes

- Two simple figures (circles + flowing shapes, no faces)
- Light threads: bezier curves with bloom effect (shadowBlur)
- Breathing glow on chest: radial gradient pulsing
- Fireflies: particles with decay lifecycle
- Color palette: warm white, blush pink, deep blue-purple
- No sharp edges, all soft gradients
