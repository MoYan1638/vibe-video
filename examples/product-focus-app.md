# Example: Focus App Product Promo

**Style**: minimal-line  
**Aspect**: 9:16  
**Duration**: 15s

---

## Prompt

```
用 vibe-video 做一个 15 秒 9:16 产品宣传视频。
产品：一款专注 App。
风格：minimal-line。
情绪主线：痛点→方案→效果。
```

## Storyboard

| Time | Visual | Caption | Note |
|------|--------|---------|------|
| 0-3s | Phone lighting up repeatedly, attention shattering | 手机每亮一次，注意力就碎一次 | Pain point |
| 3-8s | Phone icon, notifications folding into a star | 这款 App 把通知折叠成一颗星星 | Solution |
| 8-12s | User opens app, all messages delivered at once | 只在你主动打开时，才把所有消息一次给你 | Benefit |
| 12-15s | Star emoji + clean phone screen | 专注，不是不联系，是选择什么时候联系 | Tagline |

## Rendering Notes

- Black/white line art on white background
- Phone: rounded rectangle outline
- Notification icons: simple geometric shapes (circle, square, triangle)
- Star: animated path drawing (lineDashOffset technique)
- Single accent color: coral or blue
- No fill, only 1-2px strokes
