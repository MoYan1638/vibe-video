# Visual Metaphor Library

Map abstract concepts to concrete visual representations. The AI selects appropriate metaphors based on the user's topic and emotional arc.

## How to Extend

When the user provides a concept not in this library:

1. **Identify the core feeling** — What does this concept feel like? (tight, expansive, heavy, light, sharp, soft)
2. **Find a physical analogy** — What in the physical world behaves similarly? (elastic, magnetic, fluid, brittle)
3. **Translate to primitive shapes** — Circle (soft/organic), Line (connection/direction), Polygon (structure/barrier), Particle (energy/essence)
4. **Define the motion** — How does it move? (pulse, spiral, drift, explode, converge, morph)
5. **Assign color emotion** — Warm (approach/comfort), Cool (distance/calm), Saturated (intensity), Desaturated (melancholy)

The AI will generate Canvas code based on this 5-step translation.
